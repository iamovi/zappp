Installation

Install Zappp globally to use the zappp command anywhere, or add it to your local project:

Global Installation (Recommended)

npm install -g zappp

Local Project Dependency

npm install zappp --save-dev

Quick Start

Navigate to your project directory and run:

Terminal
cd my-project
zappp

Your server will spin up on http://localhost:3000. Edits to HTML, CSS, JavaScript, or static assets will trigger an automatic browser reload.

Usage Guides

Serving Custom Directories

Pass any folder path as an argument to serve that specific directory:

Terminal
zappp ./public
zappp ./dist
zappp ../my-website

Configuring Port and Host

Change the port with -p and bind to a specific network host with --host:

Terminal
zappp -p 8080
zappp --host 127.0.0.1 -p 5000

Auto-Opening Browser

Launch your default browser automatically on startup with -o:

Terminal
zappp -o
zappp ./dist -p 4000 -o

CLI Options Reference

Overview of all flags and options supported by the Zappp CLI:

Option Alias Type Default Description
--port <number> -p Number 3000 Port for HTTP and WebSocket server (1–65535).
--host <address> — String 0.0.0.0 Network interface to bind to (use 127.0.0.1 for local only).
--open -o Boolean false Opens default browser on startup.
--no-browser — Boolean true Disables opening the browser.
--version -v Flag — Shows current version and checks npm registry for updates.
--help -h Flag — Displays the CLI help manual.

Core Architecture

WebSocket Live Reload

When an HTML file is requested, Zappp injects a lightweight client script before </body> or </html>. It connects over WebSocket to the server, and whenever files change, a reload event triggers an instantaneous browser refresh.

Case-Insensitive Injection
Whether your markup uses lowercase </body> or uppercase </BODY>, Zappp injects accurately at the exact closing tag position.

Smart Reconnect (Exponential Backoff)

When the server stops, Zappp's injected client retries connecting using an exponential backoff curve (1s, 2s, 4s, up to 10s). It stops after 20 attempts, eliminating infinite reload loops.

Directory Listing UI

If a folder lacks an index.html, Zappp renders a custom dark-mode file explorer with clean forward-slash URLs and instant folder traversal.

Silent Background Update Checks

When you start Zappp, it checks npm in the background with zero lag. When you shut down the server, if a new release exists, you'll see a clean notification alert.

Security & Traversal Prevention

Zappp uses path.relative() containment verification to guarantee that no URL can escape your root directory.

Troubleshooting & FAQ

Port Already in Use (EADDRINUSE)

If port 3000 is occupied, Zappp detects it and suggests an alternate port:

error port 3000 is already in use
       try a different port: zappp -p 8080

Accessing on Mobile / Local Network

Zappp binds to 0.0.0.0 by default and shows your network URL on boot (e.g. http://192.168.1.110:3000). Open that address on any phone or tablet on the same Wi-Fi to test responsive designs live.

Graceful Shutdown in Docker & PM2

Zappp hooks both SIGINT (Ctrl+C) and SIGTERM to cleanly close watchers and WebSocket connections.
